# Producto
- Web demo de Nova Dental, clínica ficticia medio/premium de Paraguay.
- Objetivo: mostrar calidad profesional en un portafolio y conseguir clientes para desarrollo web.
- Público: pacientes potenciales como audiencia simulada; negocios paraguayos como compradores de la demo.
- Secciones previstas: navbar, hero, tratamientos, ventajas, especialistas, testimonios ilustrativos, galería, FAQ, ubicación/contacto, CTA final, footer y botón WhatsApp.
- CTA principal futuro: consulta por WhatsApp; destino pendiente del propietario, nunca inventar un número operativo.
- Requisitos: rápida, responsive, accesible, convincente y reutilizable; fotos con licencia apropiada y condición ficticia visible.
- Fuera de alcance: chatbot, CRM, administración, automatizaciones complejas y servicios pagos. Primera etapa: base y pantalla mínima.
